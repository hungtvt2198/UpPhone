# UpPhone – Official Installer & Releases

Kho lưu trữ chính thức bộ cài đặt và cập nhật tự động của phần mềm **UpPhone – Phone Farm Shopee Video Uploader** (Windows x64).

## Tải về & Cài đặt
1. Mở mục **[Releases](https://github.com/hungtvt2198/UpPhone/releases/latest)** ở cột phải và tải file **`UpPhone_Setup.exe`**.
2. Chạy `UpPhone_Setup.exe` → bấm **Yes** khi Windows hỏi quyền Quản trị viên (UAC).
3. Chọn thư mục cài đặt (mặc định **`C:\Program Files\UpPhone`**) và bấm **Cài đặt ngay**.

## Cập nhật phiên bản mới
- Trong phần mềm UpPhone, bấm nút **Update** (*Check for Update*) ở góc dưới cùng thanh chọn tab bên trái để tự động kiểm tra, tải và nâng cấp lên phiên bản mới nhất.
- Toàn bộ `workflows/`, `templates/`, ghi chú thiết bị và cấu hình số máy của bạn được giữ nguyên 100% khi cập nhật.
